Degrees of freedom

1 Evaluate divergence

The following example uses the adaptive Group Lasso fit from Getting started. Degrees of freedom include the response dependence of the adaptive weights.

fit$dof <- dof(fit)
fit$dof
#>   lambda       df df_fixed adaptive_correction active_size active_groups
#> 1   0.30 4.979842 4.770734          0.20910803           4             2
#> 2   0.15 4.989652 4.885030          0.10462206           4             2
#> 3   0.07 6.414050 6.296359          0.11769075           6             3
#> 4   0.03 6.767343 6.715623          0.05171951           6             3
#>   rank_unpenalized df_penalized converged    kkt_error status
#> 1                1     3.979842      TRUE 8.729311e-09     ok
#> 2                1     3.989652      TRUE 4.315088e-09     ok
#> 3                1     5.414050      TRUE 3.997284e-09     ok
#> 4                1     5.767343      TRUE 2.230734e-09     ok

nzero counts coefficients; dof() computes divergence. The fixed-weight contribution is evaluated at the same adaptive solution, rather than at another fit with independently chosen weights. Numerical failures or unresolved boundary diagnostics are reported rather than silently treated as reliable derivatives.

See Theory for the distinction between divergence and Gaussian unbiasedness, and Model selection for the use of these values in criteria.

For the Lasso identity, see Zou, Hastie, and Tibshirani (2007); for partly smooth regularizers, see Vaiter et al. (2017). The Gaussian expectation identity requires Stein’s regularity and integrability hypotheses (Stein 1981). ## Zero pilots and singular weights

For inverse powers, a zero pilot radius produces an infinite weight. SPARES then imposes exact zero coefficients for that coordinate or every coordinate of that group. Shared coordinates in overlapping groups are constrained too. The remaining problem is solved on the free coordinates, retaining the original full-pilot derivatives. No large finite replacement or epsilon perturbation is used. An explicit positive lambda grid is currently required at singular zero pilots. Exactly zero is distinguished from very small.

zfit <- adalasso(diag(4),c(0,2,3,0),lambda=c(.1,.2),control=control)
zfit$beta
#>          s0       s1
#> X1 0.000000 0.000000
#> X2 1.800000 1.600000
#> X3 2.866667 2.733333
#> X4 0.000000 0.000000
dof(zfit)
#>   lambda df converged                     status
#> 1    0.1  0      TRUE exceptional_set_convention
#> 2    0.2  0      TRUE exceptional_set_convention

Finite profiles are evaluated at zero through their supplied extension (e.g. exponential weights equal one there). At any exactly zero pilot radius, dof() returns the declared exceptional-set value zero, labelled exceptional_set_convention; this is not a claim of a classical derivative at that response. Nonconverged fits still receive NA. Selection excludes such convention-only values rather than using them as complexity estimates. Custom profiles must define their values at zero, allowing positive infinity for a singular profile.
