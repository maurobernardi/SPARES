Methods

One interface for fixed and adaptive penalties

1 Choose a penalty

All fitting functions return a spares_fit object. The common lmreg() interface selects the method using penalty; the dedicated functions remain available.

Penalty Fixed weights Adaptive weights
Lasso lasso() adalasso()
Group Lasso glasso() adaglasso()
Overlapping Group Lasso ovglasso() adaovglasso()
Sparse Group Lasso spglasso() adaspglasso()
Sparse Overlapping Group Lasso spovglasso() adaspovglasso()

The overlapping-group penalty acts directly on shared coefficients, rather than introducing latent group-specific coefficient vectors. In adaptive sparse-group methods, group weights are adaptive while coordinatewise Lasso weights remain fixed.

The foundational methods are described by Tibshirani (1996), Yuan and Lin (2006) and Simon et al. (2013). For overlapping sparsity-inducing norms, see Jenatton, Audibert, and Bach (2011); for adaptive weighting, see Zou (2006) and Wang and Leng (2008). General background is provided by Hastie, Tibshirani, and Wainwright (2015).

2 Weights and regularization grids

Adaptive methods use a full-design least-squares pilot and support inverse-power, exponential and user-defined profiles with their derivatives. An identifiable pilot is required, including within each cross-validation training fold.

lambdamax() provides method-specific thresholds or certified upper bounds for constructing grids. Supply lambda to use your own grid; exactly zero pilot radii with singular weights currently require an explicit positive grid.

3 Fitted objects and predictions

  • coef(fit) extracts the coefficient path; coef(fit, s = ...) selects a regularization value.
  • predict(fit, newx = ..., s = ...) predicts on new observations; supply newz when the model includes unpenalized covariates.
  • plot(fit, xvar = "loglambda") displays the path.
  • dof(fit) evaluates local divergence, with convergence and KKT diagnostics.

Between fitted knots, extraction uses linear interpolation rather than an exact optimization refit. Without s, extraction returns the whole path. The number of nonzero coefficients, nzero, is distinct from effective degrees of freedom.

4 Scaling

standardize = TRUE scales predictors by sample standard deviations and centers them when an intercept is fitted. Coefficients and predictions are returned on the original scale, but penalties and adaptive pilots are defined in the working coordinates. The response and supplied unpenalized covariates are not scaled.

The legacy standardize.data option also rescales the response and is not supported by the DoF calculations. See the worked example for the supported workflow.

5 Function documentation in R

Use ?lmreg, ?lambdamax, ?dof, ?select, ?cv.lmreg and ?spares for argument definitions, return values and method-specific details.
